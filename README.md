# TikTok 日本商品上架助手

安装位置：`E:\TikTok商品上架助手`  
商品资料：`E:\商品资料`  
当前目标店铺：**ひよりセレクト**（TikTok JP，店铺 ID `20056043`）

## 一键流程

1. 打开桌面快捷方式 **TikTok 日本商品上架助手**。
2. 输入选品关键词或品类，点“**一键启动 Codex 流程**”。助手只准备并最大化专用 Chrome 空白窗口，不会替你打开网页。请在这个窗口手动打开 Amazon 商品页和妙手 ERP 页面；首次还需登录并启用妙手采集插件。
   - 你原先在普通 Chrome/Firefox 打开的标签不会自动接入。专用浏览器资料保存在 `E:\TikTok商品上架助手\runtime\browser-profile`，后续运行会复用。完成手动打开后，回助手点“继续运行”。
3. Codex 只检查和操作已打开的允许页面。过程中可点“**一键暂停**”；妙手助手正在处理时会在下一次接口操作前停住。遇到验证码、访问限制、风控提示或插件不可用时流程会停止，请按界面提示处理。
4. Codex 复核通过后，检查助手显示的商品资料，点“提交到 TikTok”并在确认框确认。最终发布仍由你明确确认。

如果商品已由妙手插件采集，可在“处理已采集商品”中按 ASIN 手动继续。

## 自动规则

- 禁止化妆品、食品、医药类和检测到的一线品牌。
- 标题清理妙手返回的品牌名和来源店铺名（如 `KAMANINA`），并删除 Amazon ベーシック前缀、来源商品 ID；标题和描述删除产地内容。若发现 Amazon ベーシック前缀，同时清空品牌字段。
- 每个 SKU 库存 100；SKU 重量 0.1kg；包裹重量 0.1kg，尺寸 10 × 10 × 10cm。
- 售价按人民币采集价 × 2.5 × 当次 CNY/JPY 汇率换算并四舍五入。
- 目标店铺在每次运行时核验为 ひよりセレクト / JP / `20056043`。

## 需要人工处理的情况

类目缺失、文案需翻译、售价依据无效、商品图片/SKU 缺失、命中禁品或品牌风险时，流程会暂停或要求复核。没有 Codex 复核通过状态时，助手不会开放提交按钮。采集只按网站和插件允许的方式进行；遇到验证码或风控提示立即停止，不绕过限制。提交后妙手可能异步处理，需在妙手发布列表查看最终状态。

## 文件与授权

- `E:\商品资料\商品候选资料.json`：采集后的商品资料。
- `E:\商品资料\Codex复核队列.json`：等待 Codex 复核或已提交的任务。
- `E:\商品资料\商品图片\<ASIN>`：本地可下载的商品图片。
- 妙手 API 凭据从当前 Windows 用户的 `%USERPROFILE%\.codex\skills\miaoshou-erp-common-collectbox-manage\resources\config.json` 读取，不进入商品文件或日志。
- 运行日志位于 `E:\TikTok商品上架助手\app\runs`。
- 一键流程需要本机 Codex CLI 已登录；助手通过本地受限 MCP 工具控制专用 Chrome，不依赖当前 Codex 对话的浏览器控制，也不会自动导航。浏览器仅允许访问 Amazon.co.jp 和妙手 ERP；验证码、访问限制、风控提示及最终发布操作由人工处理。

## Amazon 来源状态复核

- 在“来源库存复核”页登记已经确认上架的商品，填写 Amazon ASIN 和 TikTok 在线商品 ID。采集箱 ID 不能代替 TikTok 在线商品 ID。
- 每件商品登记后 3 天到期复核；Codex 定时任务检查已到期 ASIN，并在 `E:\商品资料\来源状态复核.json` 记录状态、证据、时间及待办 TikTok 商品 ID。
- 明确缺货会列为 `SET_TIKTOK_STOCK_ZERO`；确认来源已下架会列为 `DELIST_TIKTOK`；回到有货会列为 `REVIEW_RESTOCK`。需人工复核的页面访问错误、验证码、地区配送限制不会被判作下架。
- Codex 会先查妙手已安装技能是否有已上架商品写入能力。若没有可用且受支持的接口，就尝试通过已登录的 TikTok 商品管理页面完成操作；无法可靠定位或操作时，只导出待办 ID 和人工步骤，不会猜测商品或状态。
- “确认来源确已下架”需二次确认；完成 TikTok 操作后点击“标记所选操作已完成”。“导出待处理商品 ID”可生成 `E:\商品资料\来源复核待处理.csv`。
- 复核记录是本地状态文件；Codex 定时任务需在本机 Codex 可运行、且本地文件和浏览器可访问时完成。Amazon 页面出现访问限制或 CAPTCHA 时，停止自动检查并标记人工复核。

若接口返回授权/权限错误，请在妙手开放平台检查 App 权限和 IP 白名单；不要把 AppSecret 发到聊天。
